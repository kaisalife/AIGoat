# 02 · 设计语言与组件库

> 抄 dsh：`packages/client/ui-theme/src/styles/`（8 张 token 表）＋ `packages/client/ui-primitives/`｜协议：宿主侧｜决策：**抄**（token 前缀改为 `--ag-*`）

## 1. dsh 的设计

- **完全自研**：无 headless 库、无 Tailwind、无组件库（AGENTS.md 明令禁止）。
  CSS 方案 **CSS Modules + clsx**，每个组件伴生 `.module.css`。
- **双层 token**：
  - 基础层（8 张全局表：base / corner-shape / design-platform / focus /
    scrollbar / gradient-shadow-text / onboarding / shiki）定义原始值；
  - 语义层 `--dsw-alias-*`：特性包**只允许消费别名**，禁字面颜色。
- **主题**：light/dark/system 三态；内容字号 10–22px 可调；首屏前同步注入
  防闪烁。
- **primitives**（唯一跨包共享控件库，40+ 导出）：Button/Switch/Menu/
  MenuSurface/Modal/Toast/Tooltip/HoverCard/StateDot/TextShimmer/
  DisclosureRow/PathLabel/SegmentedControl/Pill/Tag/RiskConfirmation/
  SettingsForm/MarkdownText/CodeBlock/DiffBlock/TerminalBlock/ReadBlock/
  WebBlock/JsonTree/ImageLightbox 等。
- **视觉规范要点**：0.5px hairline 中性边框；层次靠 elevation 阴影替代边框；
  菜单 blur 材质；superellipse 圆角；卡片 R20。
- AIGoat 的 FRONTEND_PLAN.md 旧基线（≤14px 圆角、两种强调色上限）与 dsh 实际
  规范冲突时**以 dsh 为准**——本文件即新基线。

## 2. AIGoat 改造设计

### 2.1 token 体系（`web/src/styles/tokens.css` 重写，≤200 行；可拆 base+alias 两文件）

```
基础层 --ag-*：
  色板（中性灰蓝 12 阶 × 语义色 5 组）、圆角（sm 6 / md 10 / card 20 /
  superellipse）、间距（4px 基准）、字号（UI 12–14 / 内容 10–22 可调档）、
  阴影（e1–e3）、hairline、字体栈（UI 系统栈 / 代码等宽栈）、动效时长
  （120–180ms）、z-index 层表
语义层 --ag-alias-*：
  bg/surface/raised/overlay、text/primary/secondary/muted、accent、
  success/warning/danger/info、border/hairline、focus/ring、
  code-bg、diff-add/del
```

规则：**组件样式只写 `var(--ag-alias-*)`**；改主题只动基础层。暗色为默认
（IDE 场景），亮色通过 `[data-theme='light']` 切换基础层值。

### 2.2 primitives（新建 `web/src/components/primitives/`，一控件一文件 + 一 module.css）

按需引入（不照搬 40+，先落 18 个，后续板块按需追加）：

### 2.3 迁移策略

- 新板块一律 CSS Modules；存量全局 CSS（chat.css/cards.css 等 14 个）**触及
  即迁**（板块文件里列迁移清单），不搞一次性大迁移。
- `styles/base.css` 保留（重置与排版基线），其余全局表逐板块消化后删除。
- `Markdown.tsx`(34) 升级进 primitives（marked+dompurify 逻辑不动，包一层
  MarkdownText 接 token）。

### 2.4 字号与主题设置

内容字号 10–22px 档位（dsh 同款范围）入设置中心「通用」域（15）；
主题 light/dark/system 同域。`document.documentElement.dataset.theme` 驱动，
首屏在 `main.tsx` 同步设置（防闪烁）。

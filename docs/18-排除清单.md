# 18 · 排除清单（不抄什么，以及为什么）

> 用户拍板：**dsh 前端的登录等云端服务相关功能不要抄**。加上"codex 协议无对应"
> 的自然排除项，全部在此立档——设计文件里出现争议时以本文件为准。

## 1. 登录 / 云端服务相关（用户指令，无条件排除）

| dsh 模块 | 位置 | 排除理由 |
|---|---|---|
| 账号设置（登录态/浏览器授权/余额/充值/登出/onboarding） | `ui-settings-account/` | 账号体系整体不对接（PLAN.md §0 已拍板；scope.json 已剔除 account/* 全 9 项） |
| 配额通知与 Top up | `ui-chat/.../QuotaNoticeHost.tsx`、`shell.quota-notice` 槽 | 同上；自定义 provider 无厂商配额概念 |
| 消息反馈（Like/Dislike/反馈对话框） | `ui-message-feedback/` | `feedback/upload` 已剔除——往厂商云上传数据，非本地能力 |
| 产品遥测 | `packages/client/product-analytics/`、`packages/host/product-telemetry-otel/` | 不做遥测 |
| Session Log 上传开关 | `ui-settings-session-log/` | 云端排除；本地账本（06）承担可追溯性 |
| 供应商账号分组 UI | `ui-settings-models/` 内 deepseek-account 组 | 自定义 provider 是唯一模型来源（14），无账号 |
| 快捷键面板等处的登录态入口 | 各处 | 随账号体系一并排除 |

对照检查：AIGoat 三重免登录构造（`requires_openai_auth=false` 强制写、
子进程 env 剥离 OPENAI_API_KEY 等、凭证只读 provider env_key）保持不变，
不因任何板块引入账号依赖。

## 2. codex 协议无对应（scope.json 已验证，不抄）

| dsh 板块 | 排除理由 | 替代 |
|---|---|---|
| Todo 面板 | ThreadItem 19 种无 todo，无 todo 方法——本地造假清单会与模型真实状态脱节 | `plan` Item（07）覆盖任务清单诉求 |
| Workflow 运行视图 | 无 workflow 协议 | 无；多步任务靠 plan＋子代理 |
| 定时任务（Automation tasks） | 无 schedule 协议 | 无 |
| 后台任务面板（jobs） | 无对应（process/* 是命令进程事件，形态不同） | 命令卡（05）＋终端（10） |
| 插件管理（安装/开关/卸载/市场） | plugin/*、marketplace/* 已剔除；AIGoat 无插件系统 | **AF 子 Agent 注册表**（09/15）承担"能力扩展管理"角色 |
| Agent 运行模式（Standard/PTC/Minimal/Creator） | dsh 的 Cordis 插件预设是架构级概念，codex 无对应 | 权限档位 × 自定义模型的组合（12/14）覆盖轻量"预设"诉求，不单独做 UI |
| 内嵌浏览器 tab | 无协议需求；宿主能力 | 后期可选（桌面 webview），一期不做 |

## 3. dsh 架构件（有对应做法，但不按 dsh 方式做）

| dsh 架构 | AIGoat 替代 | 理由 |
|---|---|---|
| Cordis 插件内核 + slot 插件体系 | 固定槽 + 轻量注册表（tab/命令/投影三张表） | 抄皮不抄骨（00 铁律 1）；AIGoat 骨架是 Tauri + codex app-server |
| Typert Remote 传输（WebSocket mux） | Tauri invoke + event 通道（现状） | 无远程场景 |
| React-free Client 模型层 | zustand 分域 + 纯函数 reducer + 投影（16） | 保留 React 生态一致性 |
| ui-dockkit 完整布局引擎（多 pane/浮动/undo 序列） | 单列多 tab + 每线程持久化（10） | 复杂度收益比不成立 |
| 国际化 locale 字典体系 | 中文文案（现状） | 单语言用户 |
| `--dsw-*` token 命名 | `--ag-*`（02） | 只搬双层结构，不搬品牌前缀 |

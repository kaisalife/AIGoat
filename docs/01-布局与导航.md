# 01 · 布局与导航

## 1. dsh 的设计

**三栏网格 + slot 组合**，无路由（不引 react-router）：

- **左栏 sidebar**：品牌行 + New Session + 面板入口列表 + Workspaces/会话树 + 底部
  Settings；可折叠为 56px rail，窄屏自动折叠（`SIDEBAR_COLLAPSED`/`SIDEBAR_AUTO_COLLAPSE`）。
- **中栏 main**：keyed 槽——默认渲染 Conversation（会话视图），`activePanelId`
  切换为全局面板（Plugins 页、Automation tasks 页）。切换靠 entryKey 保持状态隔离。
- **右栏 rightbar**：**track 而非 box**——右栏占位者自己把面板锚定在框架右缘，
  track 只决定中栏是否让位；占位者报告 `shown/track/fullscreen` 三态，fullscreen
  保留 track 宽度但隐藏拖拽把手。
- **列宽拖拽**：`DragHandle` 用 pointer capture + rAF 节流（每帧只报一次 dx），
  拖拽中 `data-dragging` 标记、hover 才显示把手。
- **列宽求解**：`columns.ts` 集中管理（`SIDEBAR_DEFAULT`/`CENTER_MIN`/
  `RIGHTBAR_MIN/MAX/DEFAULT_RATIO` + `clampWidth`/`computeColumns`）。
- 辅助槽：`shell.bottom`（状态条）、`shell.overlay`（Toast/配额）、`shell.leading`。

源码要点（可直接对照）：
`ui-layout/src/client/AppFrame.tsx`（网格与拖拽）、`columns.ts`（常量与求解）、
`stores.ts`（activePanelId/列宽持久化）。

## 2. AIGoat 改造设计

AIGoat 已是三栏，但要补四件事：**中栏视图环、右栏 track 语义、拖拽调宽、
布局持久化**。不引入 slot 插件机制，用「固定槽 + 轻量注册表」替代。

### 2.1 中栏视图环（抄 dsh 的 conversation.view 环）

会话头部 tablist 在 **Chat ↔ Trajectory** 间切换（dsh：`ui-conversation/
skeleton/ConversationSession.tsx` + `view-selection.ts`）。视图状态入
`store/ui.ts`：`type MainView = 'chat' | 'trajectory'`。全局面板（如设置）
仍是模态（见 15），不占中栏——AIGoat 的全局面板只有设置，不值一个 slot。

### 2.2 布局骨架

```
App.tsx（装配，≤120 行）
├── layout/AppFrame.tsx        三栏 grid + DragHandle + 列宽求解（≤200）
├── layout/columns.ts          常量与 clampWidth/computeColumns（≤80）
├── layout/useLayoutStore.ts   zustand：左/右栏宽与折叠、MainView；
│                              持久化经 bridge_ui_state（≤140）
├── layout/StatusBar.tsx       现有，迁入 shell.bottom 位置（≤95，不变）
└── AppFrame.module.css
```

要点：

- **左栏**：折叠为 56px rail（图标态），折叠状态入 ui-state.json（见下）。
- **右栏**：采 track 语义——dock 面板 `position:absolute; right:0` 锚定右缘，
  中栏让位与否由 track 宽度决定（详见 [10-右栏Dock](10-右栏Dock.md)）。
  这样 dock 全屏/浮动时不会挤压消息流。
- **拖拽**：抄 DragHandle 的 pointer capture + rAF 节流实现，逐行照搬语义
  （`onLostPointerCapture` 兜底）。
- **持久化**：布局状态存**安装目录** `ui-state.json` 的 `layout` 段
  （`{ sidebar, rightbar, collapsed }`）——不用 localStorage（WebView 存储
  落 C 盘 AppData，违反 00 铁律「配置落盘」）；经 `bridge_ui_state_load/save`
  读写、保存 500ms 防抖（拖拽结束后才写盘）。右栏**每会话**布局同存该文件
  `dock.<threadId>` 段（见 10）。
- **快捷键**：`Ctrl+B` 切左栏、`Ctrl+J` 切右栏（dsh 惯例位），注册进快捷键表（15）。

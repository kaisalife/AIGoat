# 15 · 设置中心

> 抄 dsh：`packages/client/ui-settings/`（域基座：模态＋左导航）＋`ui-settings-general/`（通用域壳）｜协议：本地 settings.json＋config/read（只读参考）｜决策：**改**（现 SettingsDialog 850 行 → 域化拆分，独有功能归位）

## 1. dsh 的设计

- 800×800 **模态面板**＋左侧域导航（General / Models / Plugins / Session Log）；
  右侧域内容区滚动。
- General：外观（主题/字号）、发送行为、链接打开方式等分组表单
  （SettingsForm 控件）。
- 断线重连状态条。

## 2. 域规划（AIGoat 版左导航）

| 域 | 内容 | 来源 |
|---|---|---|
| 通用 | 主题（light/dark/system）、内容字号档（10–22）、密度、Enter 发送行为、新会话默认权限档位 | 新增（dsh General） |
| **模型** | provider/模型 CRUD、推理档位、上下文窗口、API key（环境变量/直填）、「打开位置」 | **独有**：现 SettingsDialog 模型节整体迁入，settings.rs 不动 |
| **子 Agent** | AF 注册表 CRUD、exe 存在性、能力清单/派单细则路径、**注入预览** | **独有**：现子 Agent 节迁入，registry.rs 不动 |
| 会话数据 | 配置目录管理（当前目录路径展示＋「打开位置」）、三个配置文件说明（settings.json / workspaces.json / ui-state.json）、线程排序数据、dock 残留清理 | 新增（轻量） |
| 快捷键 | 快捷键参考表（Mod+/ 风格）＋自定义（二期） | dsh ui-shortcuts 精简 |

dsh 的 Plugins 域**不抄**（无插件系统，18）；Session Log 上传域**不抄**
（云端排除，18）。断线重连条保留语义：连接状态归顶栏（现有），设置内不重复。

### 3.2 关键设计

- **配置落盘策略（全局规则，00 铁律）**：所有配置文件默认存**安装文件夹**
  （exe 旁）；不可写时回落 `%APPDATA%\dev.aigoat.app\` 并自动迁移
  （settings.rs 现有策略，提取为共享 `config_dir()`，见 17）。三个文件
  各司其职：`settings.json`（模型/子 Agent/通用设置 ui 段/线程排序
  threadOrder 段）、`workspaces.json`（工作区清单）、`ui-state.json`
  （布局 layout 段＋右栏 dock 段，前端经 `bridge_ui_state_{load,save}`
  读写、500ms 防抖——**不用 localStorage**，WebView 存储落 C 盘
  AppData）。会话数据域展示当前配置目录与三个文件的存在状态。
- **模态尺寸**：`min(800px, 90vw) × min(800px, 90vh)`，域导航在窄屏
  （<640px）折叠为顶部横向 tab。
- **SettingsForm**（primitives，02）：label+control+说明行三列布局的
  表单行组件，各域复用。
- **通用域落盘**：`useSettingsStore` 持久化到 settings.json 新增 `ui` 段
  （后端 settings.rs 加可选字段，向后兼容：旧文件无该段不报错）；
  主题/字号驱动 02 的 token 切换。
- **模型域**：现逻辑（校验/默认唯一/环境变量推荐/打开位置/回落迁移）
  原样迁移，仅拆文件；表单错误就地显示（不弹窗）。
- **子 Agent 域**：CRUD＋注入预览原样迁移；预览用 primitives/CodeBlock
  只读渲染。
- **快捷键域**：一期只读参考表（各板块注册的快捷键汇总——命令注册表
  08 的衍生数据），自定义绑定二期。

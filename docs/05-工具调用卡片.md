# 05 · 工具调用卡片

> 抄 dsh：`packages/client/ui-tool/src/client/`＋分类规则 `ui-chat/src/client/conversation-nodes/README.md`｜协议：6 种工具 Item 全支持｜决策：**抄**

## 1. dsh 的设计

- **根调用树 + 嵌套子调用**：一次工具调用可携带子调用（如子 agent 内部再调工具），
  树形渲染、层级缩进。
- **按工具名分类出活动摘要标题**：read/edit/search/code/web/commands 等类别
  决定卡片默认摘要（"Read 3 files"、"Edited 2 files"）与展开后的正文形态。
- **未注册工具走通用卡**：未知工具名渲染为通用 JSON 卡——上游新增工具不破 UI。
- 运行中 TextShimmer；完成态显示状态/退出码/耗时，可展开全文。

## 2. codex 协议支持（ThreadItem 6 种工具类）

| Item | dsh 对应类别 | 摘要形态 |
|---|---|---|
| `commandExecution` | commands | 命令行 + 退出码 + 耗时 + 输出折叠 |
| `fileChange` | edit | 文件路径 + 行数统计 + diff 块（patchUpdated 流式） |
| `mcpToolCall` | tools（按 server 名细分） | server/tool 名 + 参数摘要 + 结果折叠 |
| `dynamicToolCall` | tools（通用卡） | 工具名 + 参数 JSON 树 |
| `webSearch` | web | 查询词 + 结果数 |
| `collabAgentToolCall` | agents（子代理，见 09） | agent 名 + 任务摘要 |
| `functionCallOutput` | code | 函数名 + 输出折叠 |
| `subAgentActivity` | agents 徽章（非卡片） | — |
| `sleep` | 其他 | 等待卡（倒计时形态） |
| `hookPrompt` | 其他 | 钩子提示卡（见 12） |

**19/19 Item 已全映射**（map.rs），前端缺的只是渲染分流——现 ToolCard(78)
只有一种形态。`item/mcpToolCall/progress` 通知（C 期接线）驱动卡片内进度条。

## 3. AIGoat 改造设计

### 3.1 文件结构

```
components/cards/
├── ToolCardRouter.tsx     按 item.kind 分流的入口（≤120）
├── CommandCard.tsx        commandExecution（≤180）
├── FileChangeCard.tsx     fileChange + diff（现 36 行扩容，≤180）
├── McpToolCard.tsx        mcpToolCall + progress（≤160）
├── DynamicToolCard.tsx    dynamicToolCall 通用 JSON 卡（≤120）
├── WebSearchCard.tsx      webSearch（≤100）
├── CollabAgentCard.tsx    collabAgentToolCall（≤140，联动 09）
├── FunctionOutputCard.tsx functionCallOutput（≤100）
├── SleepCard.tsx / HookPromptCard.tsx（各 ≤80）
├── shared/CardShell.tsx   公共壳：标题/状态/耗时/折叠（≤140）
└── *.module.css
```

### 3.2 关键设计

- **CardShell 统一壳**：左状态图标（StateDot：运行/成功/失败）+ 摘要标题 +
  耗时 + DisclosureRow 展开区。各 Card 只填「摘要计算」与「展开正文」两段。
- **摘要计算纯函数** `cards/summaries.ts`（≤200）：`kind → 摘要文案`，
  可单测；中文文案（"读取 3 个文件"、"编辑 2 处"）。
- **嵌套树**：现 Entry 模型无父子——reducer 增加 `childOf` 字段
  （mcpToolCall 的子调用/子代理内部调用挂父 id）；ProcessGroup(04) 内按
  树渲染，缩进一级一档（最多 3 级）。
- **diff 块**：DiffView(127) 升级为 primitives/DiffBlock（02），
  fileChange 的 `patchUpdated` 增量合并已有逻辑保留。
- **命令输出**：TerminalBlock 承接 `commandExecution/outputDelta` 流式追加
  （行数超 500 自动截断头部，标注"已截断"）。
- **通用卡兜底**：未知 kind → DynamicToolCard JSON 树形态，保证
  `Unhandled` 哲学在卡片层同样成立。
